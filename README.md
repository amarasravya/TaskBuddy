# TaskBuddy – Productivity Management Application

TaskBuddy is a high-performance productivity dashboard built with **React**. It is designed to help users organize workflows through real-time task tracking, dynamic priority tiering, and automated progress analytics.

## 🚀 Key Features (React Implementation)
* **Dynamic State Management**: Centralized architecture to handle real-time task updates and progress calculations.
* **Progressive UI Components**: A custom dashboard that dynamically visualizes completion percentages and task volume metrics.
* **Interactive CRUD Operations**: Features intuitive "Complete" and "Delete" components for efficient workflow management.
* **Responsive Priority Filtering**: A categorization system using React hooks to sort tasks by priority (High/Medium) and domain (Work/General).

## 🛠️ Tech Stack
* **Frontend**: React.js, CSS3, HTML5
* **Tools**: VS Code, Git, GitHub

## 💻 Getting Started
1. Clone the repository: `git clone [Your-Repo-Link]`
2. Install dependencies: `npm install`
3. Start the application: `npm start`
4. Open [http://localhost:5173](http://localhost:5173) to view it in your browser.
